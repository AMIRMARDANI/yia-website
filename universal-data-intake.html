What this first test does — and does not do

  • Reads supported files in your browser and shows a preview.
  • Identifies columns, data types, missing values and likely units where possible.
  • Does not upload the selected file to the database by default.
  • Does not yet claim support for every scientific format. Each format must pass a real sample-file test before being called supported.
  • Use synthetic or de-identified data only; do not upload identifiable patient records.
